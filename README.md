# Калькулик

Калькулятор с характером: считает, болтает, злится от мата, шутит и говорит
голосом (fish.audio). Работает офлайн встроенным движком или в режиме диалога
через API (GigaChat). Есть распознавание речи, настроение и аниме-оформление.

## Что внутри

- `index.html` — всё приложение (один файл, без сборки и зависимостей).
- `сервер.py` — лёгкий локальный сервер-релей (стандартная библиотека Python):
  - `GET /api/ping` — проверка, что сервер жив;
  - `POST /api/tts` — озвучка текста через fish.audio (прокси, чтобы не светить ключ);
  - `POST /api/voices` — поиск голосов на fish.audio.
  Заодно раздаёт статику (сам `index.html`).
- `Запустить-калькулик.command` — запуск на macOS: стартует сервер и открывает страницу.

## Локальный запуск

```bash
python3 сервер.py
# затем открой http://127.0.0.1:8765
```

или двойным кликом по `Запустить-калькулик.command` (macOS).

## Голос (fish.audio)

Ключ fish.audio в коде НЕ хранится. Он берётся из:
1. переменной окружения `FISH_KEY`, либо
2. файла `fish_key.txt` рядом с `сервер.py` (в `.gitignore`).

```bash
echo 'sk-fish-ВАШ_КЛЮЧ' > fish_key.txt
```

## Деплой на Render

1. Создайте Web Service из этого репозитория (runtime: **Python**, план Free).
   - Build command: `pip install -r requirements.txt`
   - Start command: `python3 сервер.py`
2. В разделе **Environment** добавьте переменную `FISH_KEY` со своим ключом fish.audio.
3. Откройте выданный `https://<service>.onrender.com` — приложение само определит
   адрес голосового сервера (same-origin) и озвучка заработает без локального запуска.

Есть и `render.yaml` — можно развернуть через Blueprint.
